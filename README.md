# Mobile To-Do List App

A responsive, mobile-first To-Do List application built with HTML5, CSS3, and vanilla JavaScript as part of the VINIX Mobile App Development tasks.

## Features
- **Responsive Mobile Layout:** Mobile-first card interface (`max-width: 414px`) with touch-friendly controls and clean visual hierarchy.
- **Task Management (CRUD):** Add tasks with input validation, toggle completion state, delete individual tasks, and clear completed items.
- **Filter Views & Counter:** Switch between **All**, **Active**, and **Completed** tasks with a live remaining-task counter.
- **Local Storage Persistence:** Automatically saves and restores tasks in browser `localStorage` across page reloads.

## Project Structure
- `index.html` — App layout, add-task form, filter tabs, task list, and empty state
- `style.css` — Mobile-first styling, completion states, and responsive spacing
- `app.js` — Task CRUD logic, filter state, counter updates, and `localStorage` persistence
